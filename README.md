# 三轴架式机械手控制系统

基于 STC15W4K48S4 单片机的三轴机械手控制系统，用于转子精车机、开槽机等工业自动化设备的上下料作业。

## 硬件配置

| 组件 | 型号/规格 |
|------|-----------|
| 主控芯片 | STC15W4K48S4 |
| 显示屏 | 迪文串口屏 |
| 通信接口 | RS485 |
| 电机 | 两相步进电机（1.8°/步，10细分） |

## 项目结构

```

│   │   ├── uart.c/h        # 串口通信

```

## 轴配置

- **X轴**：水平移动，左右限位检测
- **Y1轴**：右侧夹持机构，独立零位 + 工件检测 + 吸爪
- **Y2轴**：左侧夹持机构，独立零位 + 工件检测 + 吸爪

## GPIO 引脚分配

### 电机控制

| 信号 | 引脚 | 说明 |
|------|------|------|
| X_DIR | P0.0 | X轴方向（1左/0右） |
| X_STEP | P0.1 | X轴脉冲 |
| X_EN | P0.2 | X轴使能（0使能） |
| Y1_DIR | P0.3 | Y1轴方向 |
| Y1_STEP | P0.4 | Y1轴脉冲 |
| Y2_DIR | P0.5 | Y2轴方向 |
| Y2_STEP | P0.6 | Y2轴脉冲 |

### 限位与检测

| 信号 | 引脚 | 说明 |
|------|------|------|
| X_R_LIMIT | P1.3 | X轴右限位（0到达） |
| X_L_LIMIT | P1.4 | X轴左限位（0到达） |
| X中间传感器 | P1.5 | X轴中间位置 |
| 成品位置有工件 | P1.6 | 成品区检测 |
| 物料位置有工件 | P1.7 | 物料区检测 |
| Y1零位 | P3.4 | Y1轴零位（0到达） |
| Y1工件检测 | P3.3 | Y1夹爪工件检测 |
| Y2零位 | P3.5 | Y2轴零位（0到达） |
| Y2工件检测 | P3.6 | Y2夹爪工件检测 |

### 吸爪与通信

| 信号 | 引脚 | 说明 |
|------|------|------|
| 左吸爪 | P4.2 | Y2轴吸爪（1吸取） |
| 右吸爪 | P4.4 | Y1轴吸爪（1吸取） |
| EN_485 | P4.1 | RS485发送使能 |

### 加工设备接口

| 信号 | 引脚 | 方向 | 说明 |
|------|------|------|------|
| 加工设备有无工件 | P2.0 | 输入 | Y3信号 |
| 加工设备异常 | P2.1 | 输入 | Y2信号 |
| 加工设备原位置 | P2.2 | 输入 | Y1信号（0原位） |
| 加工设备复位 | P2.3 | 输出 | X1信号 |
| 加工设备运行 | P2.4 | 输出 | X2信号 |

## 电机控制

### 参数

- 步距角：1.8°/步
- 细分：10（2000步/圈）
- 行程：100mm/圈
- 驱动方式：脉冲 + 方向

### S曲线加减速

使用预计算的速度表 `速度表[101]` 实现平滑加减速：
- 加速段：100步
- 减速段：100步
- 短距离运动（<200步）采用对称加减速

## 迪文屏通信协议

### 帧格式

```
帧头(2) + 长度(1) + 命令(1) + 地址(2) + 数据(n)
  5A A5     len       cmd      addr      data
```

### 常用命令

| 命令 | 代码 | 说明 |
|------|------|------|
| 写寄存器 | 0x80 | 系统控制（如切页） |
| 写变量 | 0x82 | 写用户变量区 |
| 读变量 | 0x83 | 读用户变量区 |

### 页面切换

```c
GoToPage(N);  // 跳转到页面 N
// 帧：5A A5 04 80 03 00 N
```

## 数据区定义 (CFGBUF)

| 地址 | 参数 |
|------|------|
| 0x0B*2 | 当前脉冲数 |
| 0x0C*2 | 每10ms计数 |
| 0x0D*2 | 计算速度 |
| 0x14*2 | 迪文14标志 |
| 0x15*2 | 自动端面检测 |
| 0x16*2 | 未加工到右限位距离 |
| 0x18*2 | 两端上下距离 |
| 0x19*2 | 加工位置上下距离 |
| 0x1A*2 | 未加工到加工距离 |
| 0x1B*2 | 未加工到结束距离 |
| 0x1C*2 | 左右速度 |
| 0x1D*2 | 上下速度 |
| 0x1E*2 | 加减速系数 |
| 0x20*2 | 夹取位置 |
| 0x21*2 | 铁芯直径 |
| 0x22*2 | 工件序号 |
| 0x24*2 | 当前X位置 |
| 0x25*2 | 当前Y位置 |
| 0x28*2 | 等待处位置 |

## 工件型号管理

支持 8 种工件型号，每种型号可配置：
- 型号名称（GBK编码）
- 运动参数（速度、距离等）
- 工件坐标

参数存储在 EEPROM：
- 数据区：`0x2400`
- 型号区：`0x2600`

## 调试

### 串口监视

通过 RS485 转 USB 查看通信数据。

### LED 指示

- `Blick()` 函数：错误闪烁提示

### 注意事项

1. 运动前必须检查限位状态
2. 急停信号接 P3.2（外部中断0）
3. 低电压检测会触发 LVD 中断并跳转页面 60
4. 参数修改后需调用保存函数写入 EEPROM
5. 限位开关：0 = 到达，1 = 未到达
6. 电机使能：0 = 使能，1 = 不使能
