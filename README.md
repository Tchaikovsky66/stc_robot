# 三轴架式机械手控制系统

## 项目概述

基于 STC15W4K48S4 单片机的三轴机械手控制系统，用于转子精车机、开槽机等工业自动化设备的上下料作业。系统通过 RS485 与迪文串口屏通信实现人机交互，支持多工件型号管理和参数存储。

## 系统架构

### 硬件配置

| 组件 | 型号/规格 |
|------|-----------|
| 主控芯片 | STC15W4K48S4 |
| 显示屏 | 迪文串口屏 |
| 通信接口 | RS485 |
| 电机 | 两相步进电机（1.8°/步，10细分） |

### 轴配置

- **X轴**：水平移动，左右限位检测
- **Y1轴**：右侧夹持机构，独立零位 + 工件检测 + 吸爪
- **Y2轴**：左侧夹持机构，独立零位 + 工件检测 + 吸爪

## GPIO 引脚分配

### 电机控制

| 信号 | 引脚 | 说明 |
|------|------|------|
| X_DIR | P0.0 | X轴方向（1左/0右） |
| X_STEP | P0.1 | X轴脉冲 |
| X_EN | P0.2 | X轴使能（0使能） |
| Y1_DIR | P0.3 | Y1轴方向 |
| Y1_STEP | P0.4 | Y1轴脉冲 |
| Y2_DIR | P0.5 | Y2轴方向 |
| Y2_STEP | P0.6 | Y2轴脉冲 |

### 限位与检测

| 信号 | 引脚 | 说明 |
|------|------|------|
| X_R_LIMIT | P1.3 | X轴右限位（0到达） |
| X_L_LIMIT | P1.4 | X轴左限位（0到达） |
| X中间传感器 | P1.5 | X轴中间位置 |
| 成品位置有工件 | P1.6 | 成品区检测 |
| 物料位置有工件 | P1.7 | 物料区检测 |
| Y1零位 | P3.4 | Y1轴零位（0到达） |
| Y1工件检测 | P3.3 | Y1夹爪工件检测 |
| Y2零位 | P3.5 | Y2轴零位（0到达） |
| Y2工件检测 | P3.6 | Y2夹爪工件检测 |

### 吸爪控制

| 信号 | 引脚 | 说明 |
|------|------|------|
| 左吸爪 | P4.2 | Y2轴吸爪（1吸取） |
| 右吸爪 | P4.4 | Y1轴吸爪（1吸取） |

### 加工设备接口

通过 GPIO 与外部加工设备（如转子精车机）交互：

| 信号 | 引脚 | 方向 | 说明 |
|------|------|------|------|
| 加工设备有无工件 | P2.0 | 输入 | Y3信号 |
| 加工设备异常 | P2.1 | 输入 | Y2信号 |
| 加工设备原位置 | P2.2 | 输入 | Y1信号（0原位） |
| 加工设备复位 | P2.3 | 输出 | X1信号 |
| 加工设备运行 | P2.4 | 输出 | X2信号 |

### 通信

| 信号 | 引脚 | 说明 |
|------|------|------|
| EN_485 | P4.1 | RS485发送使能 |

## 电机控制

### 参数

- 步距角：1.8°/步
- 细分：10（2000步/圈）
- 行程：100mm/圈
- 驱动方式：脉冲 + 方向

### S曲线加减速

使用预计算的速度表实现平滑加减速：

- `delay_table1[101]`：脉冲延时表（单位：μs）
- `速度表[101]`：对应速度值（单位：mm/s）
- 加速段：100步
- 减速段：100步

短距离运动（<200步）采用对称加减速，无匀速段。

## 迪文屏通信协议

### 帧格式

```
帧头(2) + 长度(1) + 命令(1) + 地址(2) + 数据(n)
  5A A5     len       cmd      addr      data
```

### 常用命令

| 命令 | 代码 | 说明 |
|------|------|------|
| 写寄存器 | 0x80 | 系统控制（如切页） |
| 写变量 | 0x82 | 写用户变量区 |
| 读变量 | 0x83 | 读用户变量区 |

### 页面切换

```c
// 跳转到页面 N
GoToPage(N);
// 帧：5A A5 04 80 03 00 N
```

### 数据读写

```c
// 写数据到地址
给迪文上传数据(address, data);

// 读取所有参数
获取迪文所有数据();
```

## 工件型号管理

系统支持 8 种工件型号（工件1-8），每种型号可配置：

- 型号名称（GBK编码，迪文屏显示）
- 运动参数（速度、距离等）
- 工件坐标（X/Y1/Y2位置）

参数存储在 EEPROM：
- 数据区：`0x2400` 起始
- 型号区：`0x2600` 起始

### 相关函数

```c
保存数据(工件序号);           // 保存当前工件参数
从扇区中读取(addr, len, buf); // 读取 EEPROM
恢复出厂设置();               // 恢复默认参数
```

## 调试

### 串口监视

通过 RS485 转 USB 查看通信数据。

### LED 指示

- P4.1 (EN_485)：通信状态指示
- `Blick()` 函数：错误闪烁提示

### 常见问题

| 问题 | 排查 |
|------|------|
| 电机不转 | 检查使能信号、脉冲输出、驱动器电源 |
| 位置不准 | 确认细分设置、机械传动比 |
| 通信失败 | 检查 485 接线、波特率、发送使能时序 |
| 限位不触发 | 检查传感器接线、确认高低电平逻辑 |

## 注意事项

1. 运动前必须检查限位状态
2. 急停信号接 P3.2（外部中断0）
3. 低电压检测会触发 LVD 中断并跳转错误页面
4. 参数修改后需调用保存函数写入 EEPROM
